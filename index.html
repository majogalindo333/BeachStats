Escala técnica

`#` excelente / punto directo · `+` positivo · `/` overpass (recepción y armado) · `-` negativo · `=` error grave. Las descripciones cambian según el fundamento. La evaluación y el equipo que ganó el rally se guardan por separado.

Evaluaciones por jugadora y fundamento

Positivo = (# + +) / acciones evaluadas. Eficiencia de ataque = (kills − errores) / ataques evaluados. Estas métricas solo usan scouting completo.

Side-out y break point por equipo

Side-out: rallies ganados al recibir / rallies recibidos. Break point: rallies ganados al servir / rallies servidos. Requiere que la jugadora o equipo sacador estén correctamente registrados.

Uso en iPad, iPhone y computadora

Esta versión funciona como archivo HTML independiente y no necesita servidor para el registro. Los datos se guardan en el almacenamiento del navegador siempre que el dispositivo lo permita. La sincronización entre dispositivos y el trabajo simultáneo de varias personas aún no están implementados. Utiliza archivos JSON para transferir información. En Safari, conserva respaldos periódicos en la app Archivos.

Si necesitas acceso desde varios dispositivos a la vez, la siguiente etapa será convertirla en una aplicación alojada con usuarios, base de datos y sincronización.
