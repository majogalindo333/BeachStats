# CentralCourt — PWA

Aplicación para scouting, análisis y planificación de vóley playa.

## Activar sitio en GitHub Pages

1. Entrar en Settings > Pages.
2. En Build and deployment, seleccionar **Deploy from a branch**.
3. Elegir rama **main** y carpeta **/(root)**. Pulsar **Save**.
4. Abrir `https://majogalindo333.github.io/BeachStats/` en Safari.
5. Usar Compartir > Añadir a pantalla de inicio.

Los datos de partidos y sesiones se guardan localmente en el navegador, no en GitHub. Las instalaciones en Safari y en pantalla de inicio pueden tener almacenamiento separado. Para trasladar registros, exportar/importar JSON desde la app. GitHub Pages publica esta aplicación públicamente y no tiene acceso mediante contraseña.
